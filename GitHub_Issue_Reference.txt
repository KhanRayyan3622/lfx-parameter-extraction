Round 3: Allen Baum (mentor) clarifies REAL COMPLEXITY
- Confirmed: If something is WARL, it IS a parameter (101 field definitions)
- Discovered: 98 reference parameters via IDL (type(), sw_write(), reset_value())
- **Critical insight:** Legal value sets can depend on MULTIPLE OTHER PARAMETERS
- Example: hgatp.MODE legal set from 5 different parameters (GSTAGE_MODE_BARE + 4 SV*X4_TRANSLATION)
- Example: jvt.MODE legal set from JVT_READ_ONLY parameter
- Problem: One items.enum cannot express sets assembled from multiple parameters
- Scope adjustment: "Decidable" cases must be redefined - flat cases only

Round 4: titoatwork measurements on what's actually decidable
- 9 existing parameters use closed schema pattern (decidable)
- CSR fields consuming them NOT labeled WARL in descriptions
- Two clean patterns: $array_size (for RO/RW) and $array_includes? (for value validation)
- Some cases use only $array_size, no matching $array_includes?
- hgatp.MODE, jvt.MODE cases fall outside decidable bucket (multi-param sources)
- Recommendation: Only treat as decidable where IDL already uses closed schema
